# Agent entry point

This repository is the public essentials of the N/A design system. Read only what the task needs:

| Task | Read |
| --- | --- |
| Any page, tool or visual in the N/A look | `README.md`, then `tokens.css` and one file from `palettes/` |
| A flat identity piece (stamp, receipt, cut, window, mockup) | `SPICE.md` |
| A one-off visual from facts (landscape, status grid) | `ARTIFACTS.md` |
| A PowerPoint deck | `powerpoint/DECK-SPEC.md` |

Rules that always apply: use the tokens, never hard-code colours; flat, no shadows, corners at 4 px or less; one accent per piece; do not invent facts to fill a layout; do not edit generated SVG or HTML by hand, change the content and re-run the script; the brand marks in `assets/brand/` are not licensed for reuse (see `NOTICE.md`).
